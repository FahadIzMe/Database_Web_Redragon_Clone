# Database_Web_Redragon_Clone
This is the project for Database Administration course that I made with my group member in university. It is a clone of the Redragon website, but I have not included the entirety of the project, so I can avoid being sued for copyright. Only those files are included that do not contain an ounce of work that can be copyrighted.

# Tools Used
- WAMP
- PHP
- MySQL
- CSS
- HTML

# Notes

- The clone also includes an admin panel that presents the records present in the database along with the tables in a web format allowing CRUD operations directly on the records. This was an entirely original functionality that was not present in the official website.
- Only the PHP code and the database schema that I made are included, along with two CSS files that were coded by my group member (I will link their GitHub when they provide me the link).
- Most frontend files are not included because of copyright reasons (the pictures and the HTML/CSS structure). The frontend was worked on almost entirely by my group member. I only added the PHP code necessary for all the cart functionality and the forms in those HTML Pages but none of those files are included because of copyright reasons.
- The backend was coded by me, and the server was run using WAMP.
- I am especially proud of the cart functionality. I had not watched any tutorials or searched online how all of this is usually coded. I thought of the increment and decrement functionality of the cart items and keeping them in session by myself.
- This is my first ever project involving Web Development with a real Backend.
